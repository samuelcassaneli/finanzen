# Finanzen

Aplicação web de controle financeiro pessoal desenvolvida com React, TypeScript e TailwindCSS. O projeto oferece uma experiência integrada para monitoramento de despesas, gestão de contas de diferentes tipos (corrente, poupança, cartão de crédito e investimentos) e definição de metas financeiras.

---

## Principais Funcionalidades

* **Painel Geral (Dashboard)**: Resumo consolidado de saldos, receitas e despesas com indicadores visuais rápidos de desempenho mensal.
* **Gestão de Contas Multi-tipo**: Controle individual e consolidado de contas correntes, contas poupança, cartões de crédito e carteiras de investimento.
* **Registro e Conciliação de Transações**: Histórico detalhado de lançamentos com suporte para categorização e status de conciliação (pendente ou concluído).
* **Metas Financeiras (Goals)**: Criação de objetivos de economia com barra de progresso em tempo real e prazos definidos.
* **Relatórios e Análise**: Geração de métricas analíticas agrupadas por categorias e períodos de tempo para apoiar a tomada de decisões.
* **Suporte a PWA**: Configuração preparada para rodar como aplicativo instalável (Vite PWA).

---

## Tecnologias Utilizadas

* **React 19**: Biblioteca para construção de interfaces reativas baseada em componentes.
* **TypeScript**: Tipagem estática para maior segurança no desenvolvimento e manutenção do código.
* **TailwindCSS v4**: Estilização baseada em utilitários de alta performance e customização flexível.
* **Vite**: Bundler ultra-rápido para desenvolvimento local e compilação de produção.

---

## Instalação e Execução

1. Clone o repositório.
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Para compilar o build de produção:
   ```bash
   npm run build
   ```
